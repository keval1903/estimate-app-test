# Fix Bug

Description: Root-cause a bug in the CCAI Estimate App and apply the smallest verified fix.

1. Read root `AGENTS.md`.
2. Use the `estimate-debug` skill.
3. Inspect `git status`.
4. Reproduce or precisely identify the failing scenario.
5. Trace the relevant path before editing.
6. State root cause and targeted files.
7. Apply the smallest complete fix.
8. Use the `estimate-verify` skill.
9. Re-test the original scenario and one nearby regression.
10. Review `git diff`.
11. Report root cause, files changed, verification and any unverified item.
