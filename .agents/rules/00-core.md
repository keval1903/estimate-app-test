# Core Change Discipline

Recommended activation: Always On

- Root `AGENTS.md` is the canonical engineering contract.
- Never push to GitHub without explicit permission.
- Inspect before editing.
- Trace the real flow end-to-end for bugs.
- Reuse existing code/platform/dependencies before adding abstractions or packages.
- Prefer the smallest complete change.
- Do not refactor unrelated code.
- Never guess a schema, package script, route, RPC, environment variable or business rule: inspect it.
- Review `git status` before work and `git diff` before completion.
- Separate verified facts from assumptions.
- Never report a command or scenario as passed unless it actually ran.
